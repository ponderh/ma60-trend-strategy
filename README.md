## 策略逻辑

**核心规则**：收盘价站上MA60（60日均线）→ 买入持有；收盘价跌破MA60 → 卖出空仓

**执行方式**：
- 信号在收盘时判定
- 次日开盘价执行（模拟真实交易，不偷价格）
- 单边交易成本 0.15%（买卖各一次 0.30%）

**交易标的**：510310（沪深300ETF，0.5%/年管理费，免印花税）

## 已知缺陷

### ⚠️ 震荡市失效（2021年10月案例）

2021年9月-11月，沪深300指数在4880~4960之间横盘震荡，MA60走平在4890~4930，价格反复穿越MA60，造成**连续11次金叉死叉**，每次持有1-3天，均为小额盈亏。

这是MA60类趋势策略的**固有缺陷**，无法通过简单滤波器消除：

| 滤波器尝试 | 年化收益 | 结论 |
|-----------|---------|------|
| 无滤波 | **16.86%** | 最优 |
| 距离滤波0.5% | 8.29% | 更差 |
| MA斜率滤波 | 0.67% | 更差 |

**结论**：震荡市亏小钱，趋势市赚大钱，长期综合还是赚。接受这个缺陷。

## 策略原理

### 为什么MA60有效？

1. **趋势跟踪**：均线代表市场平均持仓成本，跌破均线意味着趋势转弱
2. **牛熊分界**：沪深300在MA60上方时，通常处于多头趋势
3. **机构化适配**：A股机构化后，MA60作为市场平均成本线更有效
